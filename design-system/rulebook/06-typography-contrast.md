# 06 · Typography & Contrast rules
Scale (size/LH, 4px grid): 8/12, 10/14, 12/18, 14/20, 16/24, 20/28, 24/32, 28/36, 32/40, 40/48. Negative tracking only ≥20px (−0.4 20–27, −0.6 ≥28); caps overlines small positive. Body/caption tracking 0. Numerics = Tabular, cream. Bind every text to a style.
Contrast: WCAG 2 AA (4.5 small / 3 large) as floor; prefer APCA — body text |Lc| ≥ 75, large ≥ 60, icons ≥ 45. Copper/meta/red = large/emphasis/icons only (per `npm run apca`). Tint backgrounds 10–16% (never full-opacity behind light text).
