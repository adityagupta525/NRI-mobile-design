AllocationBar shows portfolio split across equity/debt/gold/international as a single segmented bar with a legend.

```jsx
<AllocationBar segments={[
  { label: "Equity", pct: 62, color: "var(--copper-500)" },
  { label: "Debt", pct: 24, color: "var(--copper-300)" },
  { label: "Gold", pct: 8, color: "var(--grey-400)" },
  { label: "International", pct: 6, color: "var(--grey-600)" },
]} />
```
