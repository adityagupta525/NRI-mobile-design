ShareSheet shares a portfolio/fund. Portfolio values are sensitive, so the preview has a "Hide amounts" toggle (on by default) that masks numerals before sharing.

Motion: sheet spring-up. Haptic: selection on toggle, light on channel. Voice: n/a.

```jsx
<ShareSheet previewTitle="MY PORTFOLIO VALUE" previewValue="₹3,42,18,650" onShare={share} />
```
