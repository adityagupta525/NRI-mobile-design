GoalProgressCard shows a savings goal — copper % progress ring, current/target amounts (Tabular, Indian grouping), on-track/behind status in data colors (never decorative), and target date.

Motion: ring draw-in on mount. Haptic: none. Voice: factual status.

```jsx
<GoalProgressCard goal="Dream Home" target={5000000} current={3200000} targetDate="Dec 2028" status="on-track" />
```
