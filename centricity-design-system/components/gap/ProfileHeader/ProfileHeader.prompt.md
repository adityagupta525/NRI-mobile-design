ProfileHeader is the account/profile header — avatar slot, name, masked PAN/email subtitle, KYC status chip (verified/pending/failed) and corridor label (UAE/Singapore).

Motion: none. Haptic: none. Voice: KYC status labels.

```jsx
<ProfileHeader name="Rahul Sharma" subtitle="PAN •••• 234F" kycStatus="verified" corridor="UAE CORRIDOR" onEdit={edit} />
```
