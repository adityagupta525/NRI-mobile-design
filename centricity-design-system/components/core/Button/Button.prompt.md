Button is Centricity's tappable CTA primitive — use `primary` (brushed champagne-metal) exactly once per screen; `secondary` is a solid off-white button with dark text, `tertiary` is frosted glass, `ghost` is a copper text link.

```jsx
<Button variant="primary" size="large" fullWidth>Start your investment journey</Button>
<Button variant="secondary">Import your portfolio (CAS)</Button>
<Button variant="tertiary">Filters</Button>
<Button variant="ghost">See all</Button>
```

Variants: `primary` | `secondary` | `tertiary` | `ghost` | `destructive`. Sizes: `small` (40) | `medium` (52) | `large` (56). Props: `fullWidth`, `disabled`, `loading`, `iconLeft`, `iconRight`.
