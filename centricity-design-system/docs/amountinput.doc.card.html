AmountInput

Hero currency field for invest/SIP flows. Indian digit grouping (₹X,XX,XXX), Tabular figures, live-formatted as the user types.

States

Anatomy

① field label (Figtree 13) · ② ₹ symbol (Tabular) · ③ live value, Tabular tnum, 34px · ④ hairline baseline · ⑤ helper / min-SIP text.

Do & Don't

✓ Do
Group in the Indian system: 50,000 → 5,00,000 → 50,00,000. Always Tabular figures.
✕ Don't
Never render amounts in Figtree or with Western grouping (500,000). Never show a projected return here — that belongs in SIPCalculatorSlider with a disclaimer.

Accessibility

  • Cream value #F2EEE3 on obsidian → contrast ≥ 12:1.
  • inputMode="decimal" surfaces the numeric keypad; grouping commas are stripped before parsing.
  • Label is programmatically associated; helper/error text announced via aria-describedby.
  • Field height ≥ 44 tap target even though the visual is baseline-only.

Motion & haptics

Typedigits reflow instantly as grouping recomputes; no animation on the numeral (legibility first).
Quick-addpreset chips (+₹5k) scale 0.97 on press.
Hapticselection tick on each preset chip; none on raw typing.
