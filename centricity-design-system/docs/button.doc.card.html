Button

The tappable CTA. Exactly one primary (brushed champagne-metal) per screen; everything else steps down.

Variants & states

Anatomy

Do & Don't

✓ Do
One champagne primary anchors the thumb zone. Secondary actions use solid off-white or ghost.
✕ Don't
Never stack two primaries — the copper CTA loses its "one moment per screen" meaning.

Spacing redlines

Height 56 (lg) / 52 (md) / 40 (sm). Horizontal padding 24/20/16. Icon–label gap 8. Radius 8 (--radius-sm). Min touch target 44.

Accessibility

  • Champagne metal on ink label #0D0D0D → contrast ≥ 8:1 (AAA large).
  • Min hit target 44×44 even at size small (40 visual + tap inset).
  • Disabled uses obsidian-800 + text-disabled; still ≥ 3:1 so state is legible, and disabled is set for screen readers.
  • Loading swaps label for a spinner but keeps button width; announce with aria-busy.
  • Screen-reader label = visible text; icon-only actions use IconButton with an aria-label instead.

Motion & haptics

Pressedscale 0.97, 100ms (--motion-instant), ease-standard. Releases on pointerup/leave.
Loadingspinner 0.8s linear; no layout shift.
Hapticmedium impact on primary press; light on secondary/ghost.
Disabledno press transform, no haptic.
